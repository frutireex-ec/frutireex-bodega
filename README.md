# Fruti Reex · Bodega, producción y local

Página (GitHub Pages): https://frutireex-ec.github.io/frutireex-bodega/

- `index.html`, `version.json`: la página publicada (la arma sola la acción «Entrenar a Rex» desde `codigo/` cuando todas las pruebas pasan).
- `codigo/`: el código de la página y sus pruebas automáticas.
- `rex/`: el cerebro compartido de Rex (lo que aprende cada equipo) y cómo se entrena (`rex/README.md`).
- `AGENTS.md` / `CLAUDE.md` y `.claude/skills/entrenar-rex`: instrucciones para los agentes (Claude Code, Codex) que entrenan a Rex.
